# Quilt Studio

**Design a patchwork block, see it as a whole quilt, and get the cutting list and fabric shopping list worked out for you.**

![Quilt Studio](screenshot.png)

Quilt Studio is a small, friendly program for quilters. You colour in a block patch by patch, or start from a classic. You then see it repeated across a whole quilt with sashing, cornerstones, a border and binding. When you're happy, it tells you exactly what to cut and how much of each fabric to buy.

---

## What it does

### Design a block
- Start from one of eleven classic blocks: **Nine Patch, Shoo Fly, Churn Dash, Friendship Star, Ohio Star, Sawtooth Star, Pinwheel, Square in a Square, Hourglass, Rail Fence** and **Flying Geese**. Or design your own on a grid from 2 × 2 up to 8 × 8 patches.
- Each patch can be a plain square, a **half-square triangle**, a **quarter-square triangle** or **two rectangles**. Paint any piece with any fabric.
- **Symmetry helpers** copy every change around the block for you: mirror left-to-right, mirror four ways, or turn four ways. They're perfect for stars and medallions.
- **Surprise me!** invents a brand-new symmetrical block from your fabrics. Keep pressing it until something catches your eye.
- A small preview shows how your block looks when it's repeated.

### Choose your fabrics
- Fabrics come with prints as well as colours: plain, polka dot, stripe, gingham, crosshatch, speckle and ditsy floral.
- Six ready-made collections: *Country Cottage, Seaside, Autumn Harvest, Christmas, Amish Brights* and *Scrappy Pastels*. Picking one recolours your whole design at once.
- **Shuffle colours** swaps your fabrics around for a quick "what if?".

### Lay out the quilt
- Choose how many blocks across and down, or pick a size: cot, lap, single, double, king or wall hanging.
- Five layouts: straight repeat, turn every other block, four-way turn, mirror (kaleidoscope), and alternate with plain blocks.
- Add **sashing**, **cornerstones**, a **border** and **binding**, each in any fabric.
- The finished size is shown in inches and centimetres.

### Cutting and shopping list
For every fabric, Quilt Studio lists:
- how many strips to cut across the width of the fabric, and what to cut them into
- how much to buy, in **yards and metres**, with about 10% extra
- the binding strips, plus the **backing** and **batting (wadding)** you'll need

All cutting sizes include a ¼" seam allowance. Half-square triangles use the two-at-a-time method (finished size + ⅞"). Quarter-square triangles use finished size + 1¼". You can set the usable width of your fabric (42" by default).

You can copy the list, save it as a text file, or print it together with a picture of the quilt.

## Getting started

Quilt Studio is a single file and needs **Java 17 or newer**. If you don't have Java, you can get it free from [adoptium.net](https://adoptium.net).

1. Download `QuiltStudio.java`.
2. Open Terminal (Mac) or Command Prompt (Windows) in the folder where you saved it.
3. Type:

```
java QuiltStudio.java
```

That's it. There's nothing to install.

## Quick tips

| To do this… | …do this |
|---|---|
| Paint a patch | Choose a fabric on the left, then click or drag with **Paint** |
| Make a triangle patch | Choose **Half-square** and click a patch. Click it again to turn it |
| Turn any patch | Right-click it, or use the **Turn** tool |
| Copy a fabric from the block | Use **Pick**, then click the patch |
| Change a fabric's colour or print | Double-click it in the fabric list |
| Undo a mistake | Ctrl+Z (⌘Z on a Mac) |
| Save your design | File → Save (designs are saved as `.quilt` files) |
| Share a picture | File → Export quilt picture… |
